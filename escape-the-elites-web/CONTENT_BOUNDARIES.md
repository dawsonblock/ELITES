# Content Boundaries

## Use
- Fictional island
- Fictional elites
- Fictional survivor references
- Fictional files
- Fictional staff notes
- Fictional criminal network

## Avoid
- Direct real-person criminal accusations in gameplay
- Real victim names as characters
- Explicit sexual assault scenes
- Graphic child abuse depiction
- Player participation in abuse
- Shock-value props

## Better Horror
- A locked camera archive
- A staff memo with redactions
- A payment ledger
- A room scrubbed too clean
- A server folder named with codes
- A hidden route map
- A final feed showing evidence upload

The player should infer the horror. You do not need to show everything.
