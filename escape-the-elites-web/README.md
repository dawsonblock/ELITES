# Escape the Elites: The Broadcast

A browser-based investigative survival-horror game built with PlayCanvas, React, TypeScript, and Vite.

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Project Structure

- `src/game/` — PlayCanvas engine integration and game loop
- `src/scenes/` — Scene definitions (Dock, Service Entrance, Mansion Office, Security Wing, Bunker, Broadcast Tower)
- `src/systems/` — Gameplay systems (Player, Evidence, Stealth, Terminals, etc.)
- `src/objects/` — In-world interactables (doors, cameras, evidence pickups, etc.)
- `src/ui/` — React overlay UI (menus, HUD, evidence board, terminals, endings)
- `src/data/` — JSON-driven content (evidence, objectives, documents, endings)
- `src/types/` — Shared TypeScript types
- `src/utils/` — Utilities (event bus, storage, math, IDs)

## Content Boundaries

This game is entirely fictional. No real victim names, no explicit abuse scenes, no direct real-person criminal accusations in gameplay. Horror is implied through documents, logs, surveillance, and environmental storytelling.
