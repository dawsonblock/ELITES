# Design Document: Escape the Elites: The Broadcast

## Core Identity
A stealth evidence thriller where every document, camera feed, log, and locked room helps expose the island’s hidden network.

## Emotional Arc
Curiosity → suspicion → dread → proof → panic → exposure

## Best Comparison Mix
- Outlast-style vulnerability
- Firewatch-style environmental discovery
- Hitman-style restricted spaces
- Papers Please-style document logic
- SOMA-style cold dread

## Episode 1: The Broadcast
Runtime: 25–40 minutes

### Zones
1. Dock — teach movement, flashlight, interaction
2. Service Entrance — teach stealth and camera avoidance
3. Mansion Office — evidence board, institutional cover
4. Security Wing — surveillance scale reveal
5. Bunker Server Room — main evidence download + lockdown
6. Broadcast Tower — final upload + ending

### Evidence System
Every item must:
- unlock an objective, OR
- change ending score, OR
- corroborate another clue, OR
- reveal a timeline node, OR
- open an optional route

### Stealth
- Visibility based on distance, cone angle, crouch, flashlight, lighting zone, movement speed
- Detection states: Hidden → Watched → Suspicious → Critical → Detected
- Alert states: Normal → Suspicious → Local Alert → Full Lockdown → Final Lockdown

### Endings
- Bad: upload incomplete or required evidence < 40%
- Partial: upload complete, required evidence 40–75%
- Best: upload complete, required evidence > 75%, key chain collected
- Secret: best ending + hidden archive + all corroboration links

## Quality Rule
Build a small, dense, polished route. Quality comes from lighting, sound, UI, evidence logic, tension, pacing, clean controls, stable performance, and a strong ending — not map size.
